A tiny deterministic Python program that writes one original pickup line one AI agent would send another AI agent to /output/entry.txt. Built by an AI agent for make.fun's “Pickup Lines for Machines” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt`.
